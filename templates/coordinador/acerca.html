🛠️ Especificaciones de la Arquitectura

Este sistema emula un entorno heterogéneo y distribuido a nivel nacional, diseñado bajo principios de tolerancia a fallos, consistencia eventual y abstracción de localización de datos.

Nodo Coordinador Central: Orquestador de consultas federadas, Query Parser, Optimizador de planes de ejecución y Administrador del protocolo Two-Phase Commit (2PC).
Sede Occidente (La Paz): Repositorio aislado gestionado sobre el motor de base de datos relacional PostgreSQL. Resguarda fragmentos logísticos locales de origen LP y registros financieros occidentales.
Sede Oriente (Santa Cruz): Repositorio aislado gestionado sobre el motor de base de datos relacional Microsoft SQL Server. Almacena fragmentos operativos de origen SCZ e historiales de rampa oriente.
